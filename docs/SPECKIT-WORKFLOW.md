# Spec Kit workflow with OpenCode

Install Spec Kit using its current official instructions. For a new project use `specify init . --here --integration opencode`; for an existing Spec Kit project use `specify integration install opencode`. Inspect the resulting diff before committing.

Inside OpenCode, use the installed `/speckit.*` commands. Typical flow:
1. `/speckit.constitution` — align principles with this repository's hard constraints.
2. `/speckit.specify` — define a bounded feature and acceptance criteria.
3. `/speckit.clarify` — resolve ambiguities.
4. `/speckit.plan` — plan package boundaries and validation.
5. `/speckit.tasks` — generate small independently testable tasks.
6. `/speckit.analyze` — check cross-artifact consistency.
7. `/speckit.implement` — implement tasks on a dedicated issue branch.

Do not run `specify init` over an existing setup blindly. Spec Kit command files are generated by the installed CLI and intentionally are not hand-copied into this archive.
